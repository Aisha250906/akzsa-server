# Release checklist
1. `scripts/verify.sh` green. 2. `scripts/build.sh test` green (fix compile errors from the UNVERIFIED list in the gate report). 3. `scripts/build.sh lint` reviewed. 4. Pin models (`scripts/pin-model-hashes.sh`). 5. Create keystore (`keytool -genkeypair ...`), fill `keystore.properties`. 6. `scripts/build.sh release-aab`. 7. Install a signed minified build on 3+ devices and run `DEVICE_TEST_PLAN.md`. 8. Bump `versionCode`. 9. Deploy backend with token; verify `/health`. 10. Upload to **internal testing**; read the pre-launch report. 11. Complete `PLAY_STORE_CHECKLIST.md`. 12. Tag the git commit; archive the mapping file (`app/build/outputs/mapping`) for crash de-obfuscation.
